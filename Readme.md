# PortalPy - UVV 🎓

Uma interface gráfica em Python para aceder rapidamente às notificações, atividades pendentes e notas do portal da Universidade Vila Velha (UVV), extraindo os dados em segundo plano.

**Como utilizar:**
1. Clone este repositório.
2. Instale as dependências executando: `pip install -r requirements.txt`
3. Renomeie o ficheiro `.env.example` para `.env` e preencha com a sua matrícula e senha.
4. Execute o ficheiro principal: `python portal.py`
